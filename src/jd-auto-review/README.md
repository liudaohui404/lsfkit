# JD Auto Review (京东自动评价助手)

这是一个为您在京东购物后自动填写评价、点击五星好评并提交的油猴脚本。支持批量处理待评价订单，显著节省您的手动操作时间。

## 功能特性

- **自动批量评价**：一键开始后，脚本会自动遍历待评价列表，逐个完成填写与提交。
- **智能内容生成**：支持自定义评价模板，并能自动提取商品名称填入模板（如使用 `{productName}` 占位符）。
- **五星好评**：默认自动点击所有评分项的五星。
- **可视化控制面板**：提供浮动面板，实时显示操作日志、进度，并支持随时停止或跳过。
- **自定义配置**：单次批量评价的数量以及默认评价话术。

## 安装

1. 安装油猴插件管理器，如 [Tampermonkey](https://www.tampermonkey.net/)。
2. 从 [Releases](https://github.com/liudaohui404/lsfkit/releases) 页面下载最新的 `jd-auto-review.user.js`。

## 使用方法

1. **进入列表页**：登录京东并进入 [待评价订单页面](https://club.jd.com/myJdcomments/myJdcomment.action)。
2. **配置参数**：在右侧浮动面板中输入想要评价的数量（0 代表全部）和评价模板。
3. **开始任务**：点击“🚀 开始自动评价”，脚本将引导您完成后续所有流程。
4. **自动跳转**：评价成功后，脚本会自动跳转到下一个订单，直至队列完成。

## 注意事项

- **评价字数**：京东部分商品要求评价不少于 50 字才能获得京豆，请确保您的模板长度足够。
- **安全间隔**：脚本内置了随机延迟，以模拟人工操作并规避反爬风险。
- **环境要求**：建议在最新版的 Chrome/Edge/Firefox 浏览器下运行。
