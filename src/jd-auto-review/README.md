# JD Auto Review (京东自动评价助手)

在**新版**京东评价中心（`comment.m.jd.com/pc-static`）自动填写评价、点击全五星并提交的油猴脚本。用于批量处理待评价订单，节省手动操作时间。

> 旧版 `club.jd.com/myJdcomments/...`（`ruleid` 方案）页面已下线，本脚本已迁移到新版评价中心。

## 功能特性

- **全自动批量评价**：一键开始后自动遍历待评价卡片，逐条填写并提交。
- **自动滚动加载分页**：列表按 30 条分页，脚本会滚动窗口加载全部页面后再挑选可评价项。
- **只处理低额京豆**：仅处理京豆奖励 ≤ 阈值（默认 99）的商品，高于阈值留手动处理；支持合并评价分组（读取组内“总奖励”）。
- **同标签页跳转**：解析卡片 `orderId/skuId` 后直接在当前标签页跳转，不再新开标签。
- **随机间隔**：打开下一条、点击提交前均有随机等待，模拟真人操作。
- **可视化控制面板**：浮动面板显示进度与日志，可随时停止、清空记录。
- **演练模式**：只填写文字 + 星级、不提交，便于先验证效果。

## 安装

1. 安装油猴插件管理器，如 [Tampermonkey](https://www.tampermonkey.net/)。
2. 从 [Releases](https://github.com/liudaohui404/lsfkit/releases) 页面下载最新的 `jd-auto-review.user.js`。

## 使用方法

1. 登录京东并进入 [评价中心 · 待评价](https://comment.m.jd.com/pc-static/center)。
2. 在右侧浮动面板设置“京豆上限”“评价模板”，可勾选演练模式先试跑。
3. 点击“🚀 开始全自动”，脚本会自动滚动加载分页、逐条填写并提交。
4. 全部完成后会提示，京豆一般 1 天内到账。

## 注意事项

- **京豆门槛**：部分商品页面要求“写 10 字 + 1 图或 1 视频”才给京豆；本脚本**只填文字**，这类商品可能拿不到京豆，请自行确认。
- **反爬风险**：脚本内置随机延迟以降低风险，但高频自动化仍可能触发风控或验证码，请控制频率、勿长时间连续运行。
- **页面结构**：脚本依赖当前页面 DOM 结构（`.wait-rate-card`、`.rate-comment-content-textarea`、`.scoreBox-conter-score-star-box` 等），若京东改版需同步更新。
- **环境要求**：建议在最新版 Chrome/Edge/Firefox 下运行。
